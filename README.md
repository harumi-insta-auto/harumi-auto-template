# インスタ自動投稿システム — 参照用テンプレート

note記事**『Claude Codeで毎日のインスタ投稿を自動化』の付録B**から参照される、コード一式です。

Instagram に **毎日決まった時刻に自動で投稿する**仕組みが、Pythonファイル7本と
GitHub Actionsのワークフロー2本でできています。

---

## このリポジトリの使い方

**コードを読む必要も、写す必要もありません。** Claude Code にこのURLを渡して、こう頼んでください。

> このリポジトリのコードを参照して、私のInstagramアカウント用に自動投稿の仕組みを組んでください。
> まず全体を読んで、私が用意するものを一覧にしてください。

各ファイルが何をしているか、どう頼めばいいかは、**記事の付録B**に地図としてまとめてあります。

---

## ファイル構成

```
├── .github/workflows/
│   ├── daily_post.yml          … 毎日の投稿の手順書（第5章）
│   └── weekly_analytics.yml    … 週1回の数字収集の手順書（第7章）
├── content_generator.py        … 投稿の中身（文章＋画像）を作る（第4章）
├── instagram_poster.py         … Instagramに投稿する（第3章）
├── notify.py                   … 失敗したときにメールで知らせる（第5章）
├── analytics_fetcher.py        … 数字を取ってくる（第7章）
├── analytics_report.py         … 数字をレポートにまとめる（第7章）
├── email_report.py             … レポートをメールで送る（第7章）
├── validation/validate.py      … 4つの疎通テストをまとめて実行する（第3章）
└── requirements.txt            … 必要な部品の一覧
```

---

## ⚠️ これは「雛形」です — そのままでは、あなたの投稿になりません

このリポジトリは**テンプレート**なので、アカウントの中身にあたる部分は
**空欄（プレースホルダ）にしてあります。** 記入例は `（例：…）` の形で添えてあります。

`content_generator.py` の中で、`★ここも書き換える場所です` と書かれた箇所を探してください。

| 書き換える場所 | 何を書くか |
|---|---|
| `PERSONA` | ★**いちばん大事**。どんな人物として書くか（生活・口調・【厳守】ルール） |
| `PILLARS` | 投稿テーマの柱（3〜4本）とその説明 |
| `TIME_SLOTS` | 投稿時刻に、あなたが実際に何をしているか（**平日と土日を別々に**） |
| `BASE` / `BASE_DARK` / `ACCENT` | **ブランドカラー**。仮置きのグレーが入っているので必ず変える |
| `BRAND_HANDLE` / `BRAND_MESSAGE` | 投稿画像に入るアカウント名と、一行の中心メッセージ |
| `CORE_HASHTAGS` | 毎回付けるタグ |
| `NG_PHRASES` | 中心メッセージと矛盾するので使ってほしくない語 |
| `WORDING_FIXES` | 気になる言い回しの自動置き換え |
| `DAY_OFF_DATES` | 祝日・長期休暇（年に数回、手で足す） |
| `ALLOWED_HOURS` / `LIFE_HOURS_NOTE` | 文章に出してよい時刻 |
| `_fallback_content()` | 予備の文章（AIの生成が失敗した日に使われる） |

> **一度に全部変えないでください。** 出来上がった投稿が気に入らなかったとき、
> どれが原因か分からなくなります。1つ変えて、2〜3日ぶん生成して確認するのが結局いちばん速いです。

### キャラクター画像は入っていません

`content_generator.py` は `assets/character/expr_*.png`（表情ちがいの画像）を読みます。
著者のキャラクター画像はブランド資産なので**含めていません**。
自分の画像を同じ名前で置くか、画像を使わない形に変えてください
（`MOODS` に対応する `expr_happy` / `expr_troubled` / `expr_sleepy` / `expr_smug` /
`expr_thinking` / `expr_working` の6枚）。

## 必要なもの

```
requests / pillow / anthropic / numpy
```

鍵や設定値は**すべて環境変数**で渡します（コードには一切書きません）。
GitHubのSecrets / Variablesに何を入れるかは、**付録Bの環境変数一覧**にまとめてあります。

## 動作環境

Instagram側の仕様は変わります。手順が合わなくなったときの追い方は**付録A §7**を参照してください。
